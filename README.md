---

## ✨ Características Principales

* ⚡ **Optimización y GPU Dedicada:** Detección automática y uso forzado de tarjetas gráficas dedicadas (NVIDIA / AMD) para garantizar los máximos FPS en el juego.
* ☕ **Gestión Inteligente de Java:** Descarga automática de la versión exacta de Java necesaria (Java 8, 16, 17, 21 o Java 25 EA para las versiones más recientes como 26.x).
* 📦 **Modpacks Nativos de Modrinth:** Explora, busca e instala modpacks enteros y sus dependencias con un solo clic sin salir del launcher.
* 🎨 **Shaders y Fabric:** Integración perfecta con Iris Shaders y descargador de versiones de Fabric compatible al 100%.
* 🔐 **Seguridad Microsoft:** Inicio de sesión oficial y seguro a través de Microsoft (Device Code Auth).

## 🖥️ Requisitos del Sistema

* **Sistema Operativo:** Windows 10 o Windows 11 (64-bits).
* **Conexión a Internet:** Requerida para la primera descarga de librerías y assets del juego.
* **Cuenta de Minecraft:** Cuenta oficial de Microsoft/Mojang para jugar en línea.
